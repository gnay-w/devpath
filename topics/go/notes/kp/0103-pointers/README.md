## 正文

### 和 Java 差在哪

| | Java | Go |
|---|---|---|
| 变量里装什么 | 引用类型几乎总是「地址」 | **默认都是值**；要地址就显式 `&` / `*` |
| 传参 | 对象传引用拷贝（仍指向同一对象） | **整份值拷贝**；传指针才共享 |
| 语法 | 无 `*` | `p := &x` 取址，`*p` 解引用 |

一句话：Go 不会偷偷变成引用；要共享，自己传指针。

### 值拷贝 vs 指针共享

```text
值拷贝：          指针共享：

  a: [42]           a: [42] <── p
       │                   ▲
  赋值拷贝                  │
       ▼                   │
  b: [42]           *p 改的就是 a
```

- `b = a` / `f(a)`：两份独立内容，改副本不影响原件。  
- `p = &a` / `f(&a)` 再 `*p`：共享同一块数据。

**指针变量本身也是值**（里面装地址）。`q := p` 拷的是地址；`*q` 仍指向同一块。

### 改 struct：传值不够，传 `*T`

```go
func rename(u User)  { u.Name = "Bob" }  // 改副本，外面不变
func rename(u *User) { u.Name = "Bob" }  // 字段自动解引用，等价 (*u).Name
```

调用：`rename(&u)`。

### 指针零值

`var p *T` → `p == nil`。对 nil 解引用 / 写字段会 panic。  
要指向真实值：先有变量再 `&`，或 `&T{}` / `new(T)`。

### 易混：改「指针变量」≠ 改「指向的数据」

```go
func rebind(p *int) { x := 100; p = &x } // 只改了函数里的 p 拷贝
func mutate(p *int) { *p = 100 }         // 改共享数据
```

要改调用方那个指针变量本身，才需要 `**T`（日常少见）。

## 最小例子

```go
u := User{Name: "Alice"}
```

## 验收题（已通过）

1. `rename(User)` 后仍是 Alice —— 传值拷贝。
