# 0107 append、cap 与 copy

## 目标

能举出「append 后旧切片是否仍共享」的例子；对应 curriculum 验收。

## 写本篇时的基础假设

- 0106 已会：header = ptr+len+cap；子切片默认共享底层；打印只看 len。  
- 缺口：何时换 backing、旧标签是否仍共享；独立副本怎么做。

## 正文

### 一句话

`append` 往当前视图后面塞元素：`len < cap` 就原地写；`len == cap` 就**换更大底层并拷贝**。  
换没换决定旧切片还跟不跟你共享——**不要猜，看有没有扩容**。要稳妥独立副本用 `copy`。

### cap 与 append

| | 含义 |
|--|------|
| len | 当前窗口有几个（`Println` 只打这些） |
| cap | 从起点起底层还剩多少格，给 append 填 |

`make([]int, 2, 4)`：底层 4 格，标签只看前 2 格。再 `append` 一个 → 填第 3 格，len=3，cap 仍 4（不换房）。

### 扩容 vs 不扩容（验收核心）

| 情况 | 旧切片还共享吗？ |
|------|------------------|
| `len < cap`，append 成功 | **是**（改新切片元素，旧的可能跟着变） |
| `len == cap`，append 扩容 | **否**（新旧各住各的） |

```go
// 满了 → 分手
s := []int{1, 2, 3} // len=cap=3
a := s[:2]
s = append(s, 4)
s[0] = 99
fmt.Println(a) // [1 2]

// 有空位 → 仍共享
s := make([]int, 3, 5)
s[0], s[1], s[2] = 1, 2, 3
a := s[:2]
s = append(s, 4)
s[0] = 99
fmt.Println(a) // [99 2]
```

### `copy`：要独立副本就显式拷

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
copy(dst, src) // 拷 min(len(dst), len(src)) 个；各有底层
```

别靠「碰巧 append 扩容了」当拷贝。

### 对照 Java

| Java | Go |
|------|-----|
| `ArrayList.add` 扩容藏在实现里 | 扩容规则一样存在，但多张 header 时「旧视图」仍可能指旧数组 |
| `new ArrayList<>(list)` / `Arrays.copyOf` | `copy` 到已分配好的 `dst` |

### 与前置 / 引出

- **0106：** cap 是 header 第三字段；本课说明它专门服务 append。  
- **0317 / slices 包等：** 之后工具会封装常见拷贝/增长，心智仍是「共享 vs 独立」。
