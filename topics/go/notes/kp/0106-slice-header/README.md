## 正文

### 一句话

切片变量是一张 **header**：`ptr`（起点）+ `len` + `cap`。  
`s[i:j]` 再出一张新标签，**默认共享同一底层数组**；改子切片元素 = 改那排格子。

### header 三字段

| 字段 | 含义 |
|------|------|
| ptr | 指向底层数组里某个格子（视图起点） |
| len | 当前窗口长度（`len(s)`；`Println` 只打这些） |
| cap | 从起点起底层还剩多少格（`cap(s)`；给 append 用 → 0107） |

### 试探题 2（标准答案）

```go
s := []int{1, 2, 3, 4}
a := s[:2]   // [1 2]，相对 s：含 0 不含 2
b := s[1:3]  // [2 3]
b[0] = 99
fmt.Println(s, a, b) // [1 99 3 4] [1 99] [99 3]
```

```text
底层:  [ 1 | 2 | 3 | 4 ]  → 改后 [ 1 | 99 | 3 | 4 ]
        ↑       ↑
        s,a     b 的起点

b[0] = 底层下标 1 → s 与 a 一起变；b 的 len=2，打印是 [99 3] 不是 [99 3 4]
```

### `a[x:y]` 怎么读

半开区间 **[x, y)**：含 x、不含 y；长度 = `y - x`。  
下标相对**当前这张标签**，不是永远相对最初那份数组。

### 对照 Java

| Java | Go |
|------|-----|
| `List.subList(from, to)` 常是视图 | `s[i:j]` **默认共享**底层 |
| 要独立副本常 `new ArrayList<>(sub)` | 要独立副本用 `copy`（0107） |
