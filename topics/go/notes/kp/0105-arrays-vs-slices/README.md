# 0105 数组 vs 切片

## 目标

能说清 `[n]T` 与 `[]T` 赋值/传参差异；对应 curriculum 验收。

## 写本篇时的基础假设

- 0102 已会：`[]T` 零值 nil；`[n]T` 零值是 n 个全零元素，不是 nil。  
- 用过 `[]T`；可能未把数组当成独立类型；本课钉死类型差与拷贝语义。

## 正文

### 一句话

- **`[3]int`**：定长**数组**，长度是类型的一部分；`[3]int` 与 `[4]int` 是不同类型。  
- **`[]int`**：切片——一张「标签」（指向底层数组的指针 + len + …），不是定长盒子本身。

二者**不是同一种类型**，不能直接互赋。

### 类型：不能 `s = a`

```go
var a [3]int
var s []int
// s = a  // 编译失败：cannot use a ([3]int) as []int
s = a[:]  // OK：给数组贴一张看全部元素的切片标签
```

### 赋值 / 传参：整盒拷 vs 拷标签

| | 拷什么 | 函数里改 `x[0]` |
|--|--|--|
| `[3]int` | **整盒拷贝**（所有元素） | 改的是副本，**调用方不变** |
| `[]int` | **拷切片头**（里头带着底层数组地址 + len…） | 改的是同一排格子，**调用方看得见** |

赋值同理：`b := a`（数组）各改各的；`t := s`（切片）共享底层数据。

教学中的说法（已对齐）：切片不是数组本身，也不是又 new 一份数组；它记录了底层数组的地址、起点与长度，所以改元素等于改那排格子。

### 对照 Java

| Java | Go |
|------|-----|
| 日常 `int[]` 更像引用 | 更接近 **切片** `[]T` |
| 几乎没有「值类型定长数组」日常用法 | `[n]T` 是值类型；传参会整份拷贝 |
| `ArrayList` | **不是** slice；slice 是视图/标签，扩容故事在 0107 |

日常代码 90% 用 `[]T`；要认得出 `[n]T`，并知道赋值/传参差。

## 最小例子

```go
func bumpArray(x [3]int) { x[0] = 99 } // 调用方不变
func bumpSlice(x []int)  { x[0] = 99 } // 调用方变了

a := [3]int{1, 2, 3}
s := a[:] // 类型：[]int，不是把数组「变成」切片类型赋值
```

## 验收题（已通过）

1. `s = a` 类型不匹配；正确：`s = a[:]`。  
2. 数组参数值拷贝 → 改不影响原数组；切片拷标签（地址+起点+长度）→ 改元素即改原底层数组。
