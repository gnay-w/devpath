## 语言核心

**已会**

- 能读常见 Go 语法，能猜代码意图  
- 知道指针语法、slice/map 基本用法  
- 能写带 `go func` / `WaitGroup` 的结构  
- **0101：** 首字母导出；字段小写 + `NewUser`/`Name()`；`internal/` 编译器强制；import path = module + **目录**；**import 的是包**（不是文件）  
- **0102：** 常用预声明类型（bool/string/int/byte/rune/float64 等）；零值表；「零值可用」= 合法空、少判空，≠ 一切操作都安全；nil map 可读/`len`、不可写；struct 值字段嵌套铺零值、指针字段零值 `nil`；`[]T` 零值 nil vs `[n]T` 全零元素  
- **0103：** 默认传值拷贝；要共享传 `*T` / `&x`；指针变量本身也是值（`rebind` 无效，须 `*p=...`）；字段可自动解引用；指针零值 `nil` 不可解引用  
- **0104：** 逃逸分析——生命周期可能超出栈帧则上堆；`return &局部` 安全（`moved to heap`）；纯值返回通常不逃逸；`any`/`interface{}` 盒子常带指针故内容易逃逸；会用 `go build -gcflags=-m`（可加 `-l`）看提示；语义对错 ≠ 分配位置  
- **0105：** `[n]T` 与 `[]T` 不同类型，须 `a[:]`；数组赋值/传参整盒拷贝；切片拷标签（地址+起点+长度）共享底层，改元素外面可见

**不稳 / 缺口**

- **slice 共享底层数组：** 试探题 2 答错；header（ptr/len/cap）需专练 → **0106（当前）**  
- **interface nil：** 试探题 3 不会；(type,value) 二元组未建立 → 0113  
- error 包装（Is/As）、接收者选择、嵌入组合：未测，默认待补  

**易混（Java 迁移）**

- 对象/引用 ≈ 到处堆上 → Go 常栈上，逃逸才堆（0104 已对齐）  
- `List.subList` / 拷贝直觉 → slice 视图常共享数组（0105 已对齐「拷标签」；子切片细节 → 0106）  
- `null` → 带类型的 nil 仍可能让 interface ≠ nil；零值 `""`/`0`/`nil` 常是合法空而非异常  
- import：易把 path 末段当成「文件名」→ 实为目录；import 引入的是 package  
- 指针零值是 `nil` 不是整数 `0`；`[n]T` 不是 nil  
- Java 对象参数像「始终传指针」→ Go 默认值拷贝，要共享须显式 `*`  
- 「返回值就不逃逸」不成立：值里若带着回指数据的指针（`*T`、`any`），数据仍可能上堆
