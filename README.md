# Devpath

个人技术学习仓库：遇到想学的技术，按主题维护笔记、实验和小项目。

## 怎么用

1. 复制 `_templates/topic/` → `topics/<tech>/`
2. 填写该主题的 `README.md`
3. 在下方技术表加一行
4. 按需往 `notes/` / `labs/` / `projects/` 里写

详细约定见 [CONVENTIONS.md](./CONVENTIONS.md)。
